# Test Coverage Analysis Guide

This guide explains how to analyze test coverage for the Relias Assistant project using different tools and approaches.

## Overview

The project uses xUnit for testing with the following test projects:
- `tests/Relias.Assistant.UnitTests/` - Unit tests for all components
- Built-in coverlet collector for coverage analysis
- Optional dotCover for advanced coverage analysis

## Quick Start (Recommended Approach)

### 1. Run Tests with Coverage
```bash
dotnet test Relias.Assistant.sln --collect:"XPlat Code Coverage" --results-directory:TestResults
```

### 2. Generate HTML Report
```bash
# Install ReportGenerator (one-time setup)
dotnet tool install --global dotnet-reportgenerator-globaltool

# Generate HTML coverage report
reportgenerator -reports:"TestResults\**\coverage.cobertura.xml" -targetdir:"CoverageReport" -reporttypes:"Html"
```

### 3. View Results
Open `CoverageReport\index.html` in your browser to see detailed coverage information.

## Using dotCover (Alternative Approach)

### Installation
```bash
# Install dotCover globally (one-time setup)
dotnet tool install --global JetBrains.dotCover.GlobalTool
```

### Basic Usage
```bash
# Generate coverage snapshot
dotCover cover /TargetExecutable="C:\Program Files\dotnet\dotnet.exe" /TargetArguments="test Relias.Assistant.sln" /Output="coverage.dcvr"

# Generate HTML report from snapshot
dotCover report /Source="coverage.dcvr" /Output="dotcover-report.html" /ReportType="HTML"
```

### Configuration File Approach
Create `dotcover-config.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<AnalyseParams>
  <TargetExecutable>C:\Program Files\dotnet\dotnet.exe</TargetExecutable>
  <TargetArguments>test Relias.Assistant.sln --logger "console;verbosity=minimal"</TargetArguments>
  <TargetWorkingDir>F:\github\Relias\relias-assistant</TargetWorkingDir>
  <Output>coverage.dcvr</Output>
  <Filters>
    <ExcludeFilters>
      <FilterEntry>
        <ModuleMask>*.Tests</ModuleMask>
      </FilterEntry>
      <FilterEntry>
        <ModuleMask>*.UnitTests</ModuleMask>
      </FilterEntry>
      <FilterEntry>
        <ModuleMask>*.IntegrationTests</ModuleMask>
      </FilterEntry>
    </ExcludeFilters>
  </Filters>
</AnalyseParams>
```

Then run:
```bash
dotCover cover dotcover-config.xml
```

## Coverage Report Types

### Cobertura XML (Default)
- Generated automatically with `--collect:"XPlat Code Coverage"`
- Located in `TestResults/*/coverage.cobertura.xml`
- Can be converted to HTML using ReportGenerator

### HTML Reports
- Human-readable coverage reports
- Show line-by-line coverage
- Include summary statistics
- Generated by ReportGenerator or dotCover

### dotCover Snapshots (.dcvr)
- Binary format used by JetBrains tools
- Can be opened in JetBrains IDEs
- Can be converted to various report formats

## Common Commands Reference

### Test Execution
```bash
# Run all tests
dotnet test Relias.Assistant.sln

# Run tests with minimal logging
dotnet test Relias.Assistant.sln --logger "console;verbosity=minimal"

# Run specific test project
dotnet test tests/Relias.Assistant.UnitTests/Relias.Assistant.UnitTests.csproj
```

### Coverage Analysis
```bash
# Basic coverage with coverlet
dotnet test --collect:"XPlat Code Coverage"

# Coverage with specific output directory
dotnet test --collect:"XPlat Code Coverage" --results-directory:TestResults

# Coverage with additional settings
dotnet test --collect:"XPlat Code Coverage" -- DataCollectionRunSettings.DataCollectors.DataCollector.Configuration.Format=cobertura
```

### Report Generation
```bash
# HTML report with ReportGenerator
reportgenerator -reports:"TestResults\**\coverage.cobertura.xml" -targetdir:"CoverageReport" -reporttypes:"Html"

# Multiple report types
reportgenerator -reports:"TestResults\**\coverage.cobertura.xml" -targetdir:"CoverageReport" -reporttypes:"Html;JsonSummary;Badges"

# dotCover HTML report
dotCover report /Source="coverage.dcvr" /Output="report.html" /ReportType="HTML"
```

## Troubleshooting

### dotCover Issues
- If dotCover hangs with "Usage: dotnet [commands]" message, the target arguments may not be passed correctly
- Try using configuration file approach instead of command-line arguments
- Ensure dotCover is properly installed: `dotCover version`

### Coverage Not Showing
- Verify test projects have `<IsTestProject>true</IsTestProject>` in their .csproj
- Check that coverlet.collector package is referenced in test projects
- Ensure source projects are referenced by test projects

### Missing Reports
- Check TestResults directory exists and contains coverage files
- Verify ReportGenerator is installed: `reportgenerator --help`
- Ensure file paths use correct separators for your OS

## Extracting Coverage Percentages

To quickly extract line and branch coverage percentages from generated reports:

### From Cobertura XML Files
```bash
# Find coverage files
Glob "**/coverage.cobertura.xml"

# Extract line and branch coverage percentages
Grep "line-rate|branch-rate" path/to/coverage.cobertura.xml
```

The output will show:
- `line-rate="0.1316"` = 13.16% line coverage
- `branch-rate="0.0607"` = 6.07% branch coverage

### From HTML Reports
Open `CoverageReport/index.html` in browser - percentages are displayed prominently on the summary page.

### From dotCover Reports
```bash
# Generate XML report for easy parsing
dotCover report --source="coverage.dcvr" --xml-report-output="coverage-report.xml"

# Extract percentages
Grep "CoveredStatements|TotalStatements|CoveredBranches|TotalBranches" coverage-report.xml
```
