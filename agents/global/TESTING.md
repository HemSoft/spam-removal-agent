# Testing - Guidelines for test driven development.

- Follow test-driven development: write failing tests first, then implement code to make them pass.
- Always make sure to write failing and passing tests.
- Strive to improve test coverage with each change. See /agents/DOTCOVER.md for more information.
- Never write methods or sections of code that only serve testing purposes.
